# Manuscript

`main.tex` — IEEE conference format (`IEEEtran`, `[conference]`).

## The rule for numbers

**Never type a numeric result into `main.tex`.** Every figure quoted in the
paper comes from a macro in one of two generated files:

| File | Generated by |
|---|---|
| `results_macros.tex` | `src/scripts/08_paper_numbers.py` |
| `parameters.tex` | `src/scripts/07_parameter_table.py` |

Re-run both after changing any parameter or re-running any experiment:

```bash
python3 src/scripts/07_parameter_table.py && python3 src/scripts/08_paper_numbers.py
```

Unmeasured quantities render as bold `??` in the PDF rather than silently
becoming plausible-looking numbers. **Search the compiled PDF for `??` before
submitting.**

Currently unfilled, and deliberately *not referenced* anywhere in the
manuscript, because the paper does not claim what has not been measured:

- `\BenchWarpCUDA`, `\Speedup` — no GPU was reachable during this work
- `\FieldN`, `\FieldMAE`, `\FieldSpecies` — no plant measurements collected

If GPU numbers or field measurements arrive, re-run the generators and then
add the corresponding subsections; the scaffolding in `main.tex` marks where.

## Building

No LaTeX toolchain is installed on the development machine. Either:

**Locally** —

```bash
sudo apt install texlive-latex-recommended texlive-publishers texlive-fonts-recommended texlive-latex-extra latexmk
```

```bash
cd paper && latexmk -pdf main.tex
```

`texlive-publishers` is the package that provides `IEEEtran.cls`.

**Or Overleaf** — upload `main.tex`, `refs.bib`, `parameters.tex`,
`results_macros.tex`, and the four referenced images from `results/`. Note
that figure paths are written as `../results/...`; flatten them if you upload
images into the project root.

## Verifying without compiling

`main.tex` has been checked for balanced environments and braces, resolvable
figure paths, defined citation keys, and non-dangling cross-references. That
catches structural breakage but is not a substitute for a real compile — do
one before submitting.

## Bibliography

Every entry in `refs.bib` was verified to exist on 2026-09-12. Three entries
carry `note` fields flagging author lists that still need completing from the
publisher listing. **Do not add an entry that has not been checked against the
actual paper.**

## Before submission

1. Confirm advisor co-authorship and author ordering (marked in `main.tex`).
2. Complete the acknowledgment section.
3. Complete the three flagged author lists in `refs.bib`.
4. Compile and search the PDF for `??`.
5. Check the page limit for the target venue.
